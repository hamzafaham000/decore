# Geist

`Geist-Variable.woff2` and `GeistMono-Variable.woff2` are the latin variable
cuts of Geist and Geist Mono by Vercel, downloaded from Google Fonts.

Both families are licensed under the SIL Open Font License 1.1:
https://openfontlicense.org

They are bundled instead of fetched so the dashboard builds and renders without
a request to fonts.googleapis.com.
